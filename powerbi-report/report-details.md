# Power BI Dashboard

## Overview

Interactive weather analytics dashboard built using DirectLake.

## Features

* Daily temperature trend
* Hourly temperature pattern
* Min / Avg / Max KPIs

## Design Decisions

* NYC fog background for thematic consistency
* Glassmorphism style visuals
* Color coding:

  * Blue → Low temperature
  * Green → Average
  * Orange → High

## Goal

Provide clear insights into temperature trends and patterns.
